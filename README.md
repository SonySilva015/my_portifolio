Modern Developer Portfolio

Este é o meu portfólio pessoal, focado em alta performance e design minimalista. Desenvolvido com Next.js 15, Tailwind CSS e integrado dinamicamente com a API do GitHub.
🛠️ Tech Stack

O projeto utiliza o que há de mais moderno no ecossistema JavaScript para garantir uma experiência fluida:

    Framework: Next.js (App Router)

    Estilização: Tailwind CSS

    Animações: Framer Motion & AOS

    Ícones: Lucide React

    Dados: Integração em tempo real com a API do GitHub

✨ Funcionalidades

    Design Responsivo: Adaptado para dispositivos móveis, tablets e desktop.

    Dark Mode Nativo: Interface otimizada para conforto visual.

    GitHub Sync: Listagem automática de projetos públicos via API.

    Componentes Glassmorphism: Cards e seções com efeitos de desfoque e transparência.

    Animações On-Scroll: Feedback visual dinâmico durante a navegação.
